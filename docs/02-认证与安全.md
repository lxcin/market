# 02 · 认证与安全

## 1. 密码存储
- **BCrypt**（`BCryptPasswordEncoder`），自动加盐、不可逆。注册/重置密码均 `encode`，登录 `matches`。
- 接口与日志从不返回密码明文；`/user/info` 置空 `password`。

## 2. 图形验证码（登录）
**选型**：JDK AWT 自绘 PNG（免第三方），Redis 存储，一次性失效。

- 生成：`CaptchaUtil.randomCode(4)` + `BufferedImage`（干扰线/噪点/旋转）→ Base64 PNG。
- 存储：`auth:captcha:{captchaId}` = code，TTL 5min。
- 校验：`VerificationCodeService.verifyCaptcha` **校验即删除**（防重放），忽略大小写。
- 端点：`GET /api/user/captcha` → `{captchaId, image}`。

## 3. 短信验证码与找回密码
- 存储：`auth:sms:{phone}` = 6 位数字，TTL 5min；`auth:sms:limit:{phone}` 60s 防刷。
- 演示模式：`sms.mock=true` 时验证码写入日志并随响应返回（生产接短信网关置 false）。
- 流程：`POST /user/sms/send`（校验手机号已注册）→ `POST /user/password/reset`（校验验证码 → BCrypt 重置）。

## 4. 登录安全
- **登录失败锁定**：`auth:login:fail:{username}` 计数（TTL 15min），≥5 次 → `auth:login:lock:{username}` 锁 15min；成功登录清除计数。
- 支持**用户名或手机号**登录。
- **JWT**：`JwtUtil.generateToken` 带 `jti`（UUID），`subject=userId`，`claim=username`，HS512 签名，24h 过期。

## 5. 登出与 Token 黑名单
- 选型：**Redis 黑名单**（按 `jti`），TTL = token 剩余有效期（≤24h），过期自动清理。
- `TokenBlacklistService.blacklist(jti, ttl)` / `isBlacklisted(jti)`；JWT 过滤器解析后校验黑名单，命中则不认证 → 401。
- 端点：`POST /api/user/logout`（携带当前 token → 拉黑）。

## 6. 鉴权模型
- **过滤器**：`SecurityConfig.jwtAuthenticationFilter` 解析 token → 查库取 role → 授予 `ROLE_ADMIN`/`ROLE_USER`；黑名单校验在前。
- **URL 级**：`/api/admin/**` 需 `hasRole("ADMIN")`；商品/分类 GET 与登录/注册/验证码/支付回调 permitAll。
- **方法级（纵深防御）**：`@EnableMethodSecurity` + 6 个 Admin 控制器类级 `@PreAuthorize("hasRole('ADMIN')")`。

## 7. 越权（IDOR）修复
- 订单 `GET /order/{id}`、`PUT /order/{id}/pay`、`cancel` 均校验归属（`order.userId == 当前用户`，管理员查看放行）。
- 支付/退款/支付单操作校验 `userId`；购物车/地址天然按 userId 隔离。
- 管理员查看订单详情改走 `/admin/order/{id}`。

## 8. 接口防重提交
- 选型：**注解 + AOP + Redis SETNX**（比 JVM 锁跨实例安全）。
- `@RepeatSubmit(interval)` 标注在订单创建/直接购买、支付下单、领券；`RepeatSubmitAspect` 以 `repeat:{userId}:{方法}` 为键 `setIfAbsent`，失败抛"请勿重复提交"，业务异常时释放键。

## 9. 数据脱敏与 CORS
- `MaskUtil`：手机号 `138****8000`、邮箱 `a***e@x.com`，用于 `/user/info` 响应。
- CORS：由 `app.cors.allowed-origins` 白名单（默认 localhost:5173 等），替代原来的 `*`。

## 10. 关键 Redis 键
| 键 | 用途 | TTL |
|---|---|---|
| `auth:captcha:{id}` | 图形验证码 | 5min |
| `auth:sms:{phone}` / `auth:sms:limit:{phone}` | 短信码 / 防刷 | 5min / 60s |
| `auth:login:fail:{u}` / `auth:login:lock:{u}` | 登录失败计数 / 锁定 | 15min |
| `auth:blacklist:{jti}` | JWT 黑名单 | 剩余有效期 |
| `repeat:{uid}:{m}` | 防重提交 | N 秒 |

## 11. 验证结果
- 图形验证码获取/校验、错误验证码拒绝；手机号 + 验证码重置并新密码登录成功。
- 登出后原 token 访问 → 401。
- 连续 5 次密码错误 → 账号锁定 15min。
- 普通用户访问 `/admin/**` → 403；非本人订单 → 无权操作。
- 重复点击下单/领券 → "请勿重复提交"。
