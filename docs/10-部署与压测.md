# 10 · 部署与压测

## 1. 部署编排
### 基础设施 + 应用 `docker/docker-compose.yml`
| 服务 | 镜像 | 端口 | 说明 |
|---|---|---|---|
| mysql | mysql:8.0 | 3307→3306 | utf8mb4、`TZ=Asia/Shanghai`、`--default-time-zone=+08:00`（修时间一致性）、挂载 `init.sql` |
| redis | redis:7-alpine | 6379 | AOF 持久化、密码认证 |
| elasticsearch | **market-es:8.11.0**(自建) | 9200 | 单节点、关闭安全 |
| market-server | 构建 `market-server/Dockerfile` | 8080 | Spring Boot |
| nginx | nginx:alpine | 80 | 托管前端 dist + 反向代理 `/api` |

### 可观测栈 `docker/docker-compose.observability.yml`
prometheus(9090)、alertmanager(9093)、grafana(3000)、zipkin(9411)；Prometheus 抓取 `host.docker.internal:8080/actuator/prometheus`。

## 2. 自定义 ES 镜像（中文/拼音插件）
`docker/elasticsearch/Dockerfile`：
```dockerfile
FROM elasticsearch:8.11.0
RUN bin/elasticsearch-plugin install --batch https://get.infini.cloud/elasticsearch/analysis-ik/8.11.0 \
 && bin/elasticsearch-plugin install --batch https://get.infini.cloud/elasticsearch/analysis-pinyin/8.11.0
```
- 插件版本必须与 ES 一致；构建在离线/网络受限时用 `DOCKER_BUILDKIT=0 docker build` 复用本地 base 镜像。
- 本地 Windows 注意事项：ES 数据卷、`vm.max_map_count`、内存。

## 3. Nginx
- `location /api/` → `proxy_pass http://market-server:8080`；
- SPA 回退 `try_files $uri $uri/ /index.html`；开启 gzip。

## 5. 启动流程（本地）
```powershell
# 1) 基础设施
cd docker; docker compose up -d mysql redis elasticsearch
# 2) 观测栈（可选）
docker compose -f docker-compose.observability.yml up -d
# 3) 后端
cd ..\market-server; .\mvnw.cmd spring-boot:run   # 或 mvn -o spring-boot:run
# 4) 前端
cd ..\market-web; npm install; npm run dev         # http://localhost:5173
```
数据库初始化：首次启动 `mysql` 会执行 `docker/mysql/init.sql`（建库表 + 种子数据 + 管理员 admin/admin123）。**已有数据卷**新增表（如 `t_outbox`、`t_comment`）需手动执行或重建卷。

## 6. 压测脚本 `loadtest/seckill-loadtest.mjs`
- Node 原生 `http` + 连接池（`maxSockets=并发`），自建用户（注册直接返回 token）后并发抢券。
- 参数：`BASE`、`TEMPLATE_ID`、`USERS`、`CONCURRENCY`。
```powershell
$env:TEMPLATE_ID='7'; $env:USERS='1000'; $env:CONCURRENCY='500'; $env:BASE='http://localhost:8080/api'
node loadtest/seckill-loadtest.mjs
```
- 输出：请求数、成功/失败、耗时、QPS、P50/P95/P99。
- 结果见文档 07：1000 用户 / 500 并发 / 200 库存 → **成功 200，无超卖**，QPS≈555。

## 7. 一致性校验命令（运维常用）
```sql
-- 库存不变量
SELECT oi.book_id, SUM(oi.quantity) FROM t_order_item oi JOIN t_order o ON oi.order_id=o.id
WHERE o.status=0 AND o.deleted=0 GROUP BY oi.book_id;
-- 券不变量
SELECT id, total_count, remaining_count FROM t_coupon_template;
```
或使用管理端接口：`GET /api/admin/consistency/inventory|coupon`。

## 8. 已知环境注意
- RocketMQ 容器在本机 Docker 下不可用（broker 广播容器内网 IP），已从运行栈移除，相关链路改用 Redis Stream。
- MySQL 容器时区对齐 +08:00，避免 `NOW()` 与应用时间相差 8 小时。
- 认证/密码等敏感配置当前在 yml，生产应外部化（环境变量/配置中心）。
