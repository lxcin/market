## 技术栈总览

- **语言/框架**：Java 17、Spring Boot 3.3.5、MyBatis-Plus 3.5.7
- **存储**：MySQL 8、Redis 7、Elasticsearch 8.11
- **分布式组件**：Redisson 3.30（分布式锁/延时队列）、Micrometer（指标/链路）
- **安全**：Spring Security、JJWT 0.12、BCrypt
- **可观测**：Prometheus、Grafana、Alertmanager、Zipkin
- **前端**：Vue 3 + Vite + TypeScript + Element Plus + Pinia + Vue Router
- **部署**：Docker Compose、Nginx

> 说明：系统当前为**单体应用**，但一致性方案（预占、Outbox、延时消息、对账）均按"最终一致"设计，为后续微服务化预留了扩展路径。
