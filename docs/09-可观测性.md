# 09 · 可观测性（指标 / 日志 / 链路 / 告警）

## 1. 依赖与暴露
- 依赖：`spring-boot-starter-actuator`、`micrometer-registry-prometheus`、`micrometer-tracing-bridge-brave`、`zipkin-reporter-brave`。
- 暴露：`management.endpoints.web.exposure.include=health,info,metrics,prometheus`；公共标签 `application=market-server`；`/actuator/**` permitAll（生产应内网/鉴权）。
- 采样：`management.tracing.sampling.probability=1.0`（dev）；Zipkin `management.zipkin.tracing.endpoint`。

## 2. 指标（Metrics）
- **自动埋点**：HTTP 请求量/延迟/状态码、JVM（内存/GC/线程）、Hikari 连接池、进程 CPU。
- **业务埋点**（`BusinessMetrics`，Counter）：
  `business_order_placed_total`、`business_payment_success_total`、`business_payment_failed_total`、`business_refund_success_total`、`business_seckill_accepted_total`、`business_seckill_sold_out_total`、`business_seckill_rejected_total`、`business_login_failure_total`、`business_reconcile_mismatch_total`。
- **缓存**（`CacheHelper`）：`cache_access_total{result=hit_local|hit_redis|miss}` → 命中率。
- 接入点：下单/支付回调/退款/秒杀/登录失败/对账。

## 3. 日志（含 traceId）
```
logging.pattern.level: "%5p [${spring.application.name:},%X{traceId:-},%X{spanId:-}]"
```
- Micrometer Tracing 自动把 `traceId/spanId` 注入 MDC → 所有业务日志自带。
- 异步日志（秒杀落库、延时关单）手动把 traceId 注入 MDC。

## 4. 链路追踪（Brave + Zipkin）
- HTTP 入站、Security 过滤链、出站 RestTemplate 自动生成 span。
- 业务 span：`@Observed`（`ObservedAspect`）标注 `order.create`、`seckill.claim`、`payment.notify`、`book.detail`。

### 异步上下文传播（难点）
1. **支付回调线程池**：`AsyncConfig` 给 `payCallbackExecutor` 挂 **`ContextPropagatingTaskDecorator`**，提交时捕获的 TraceContext/MDC 传播到异步线程；出站 RestTemplate（`RestTemplateBuilder` 构建）注入 `traceparent`。
   - 结果：`sandbox 请求 → 出站 client span → /notify 入站 → handle-notify 业务 span` **同一条 trace（12 span）**。
2. **秒杀 Stream worker**：领取代把 `traceId/spanId` 写入消息；worker 用 Brave 6 `TraceContext.newBuilder()` 构造父上下文，`nextSpan(TraceContextOrSamplingFlags.create(parent))` 生成 `seckill.persist` 子 span，归入原领取 trace；MDC 注入 traceId。

## 5. 告警（Prometheus + Alertmanager）
`observability/rules.yml` 规则：
- `InstanceDown`、`HighHttpErrorRate`（5xx>5%）、`HighHttpP95Latency`（>1s）、`LoginFailureSpike`、`PaymentFailureSpike`、`SeckillSoldOutSpike`。
- `prometheus.yml` 挂载 `rule_files` 与 `alerting.alertmanagers`；`alertmanager.yml` 默认路由。
- 验证：制造登录失败 → `LoginFailureSpike state=firing` → Alertmanager `status=active`。

## 6. Grafana
- 预置数据源（Prometheus）+ 看板 `Market Overview`：HTTP QPS、P95 延迟、业务计数器、缓存命中率、JVM Heap、Hikari 活跃连接（file provisioning）。

Prometheus `:9090`、Alertmanager `:9093`、Grafana `:3000`(admin/admin)、Zipkin `:9411`。

## 8. 取舍
- dev 全量采样（1.0），生产建议 0.1；`@Scheduled` 每 tick 会生成 task trace，属噪音可关闭。
- 日志仅本地文件 + traceId，未接 ELK/Loki；告警 receiver 为空（未接真实通知渠道）。
