# 03 · 商品与搜索（Elasticsearch）

## 1. 为什么上 ES
- 原搜索走 MySQL，且 **FULLTEXT 索引是死索引**（SQL 用 `LIKE '%kw%'`，未走 `MATCH...AGAINST`），中文效果差。
- ES 提供：中文分词、BM25 相关度排序、字段权重、聚合分面、高亮、拼音检索。

## 2. 索引建模（版本化索引 + 别名）
- 实体索引 `book_v{时间戳}`，**别名 `book`**（`is_write_index=true`），读写都走别名。
- 目的：**零停机重建**——建新索引 → 灌数据 → `updateAliases` 原子切换 → 删旧索引。
- 索引创建用**低层 RestClient + 原生 JSON**（自定义分词器在 Java 强类型客户端里较绕）。
- `dynamic: strict` + `number_of_replicas: 0`（单节点即 green）。

### 分词器
```
filter: pinyin_filter { type: pinyin, keep_joined_full_pinyin: true, keep_first_letter: true, keep_full_pinyin: false }
analyzer: pinyin_analyzer { tokenizer: keyword, filter: [pinyin_filter] }
```
- 中文正文/标题/作者：`ik_max_word`（索引）+ `ik_smart`（查询）。
- 拼音：`title.pinyin` / `author.pinyin` 子字段用 `pinyin_analyzer`。实测 `周志华 → zhouzhihua | zzh`。

### Mapping（动态严格）
| 字段 | 类型 | 说明 |
|---|---|---|
| title | text(ik) + `keyword` + `pinyin` | 书名：检索 + 精确/聚合 + 拼音 |
| author | text(ik) + `keyword` + `pinyin` | 作者：同上 |
| description | text(ik) | 简介 |
| categoryId | long | 精确过滤 |
| categoryName | keyword | 分类分面（聚合/筛选） |
| coverImage | keyword | 原样 |
| price | double | 范围过滤/排序 |
| rate / sales / status | double / integer / integer | 排序 / 过滤 |

## 3. 数据同步
- 启动 `ProductSearchInitializer` → `rebuildIndex()`（版本化重建 + 别名切换）。
- 每 5 分钟 `refreshIntoAlias()` 全量刷新（商品量小；生产应改增量/Canal）。
- Admin 增删改商品 → `indexBook/deleteBook`（实时）。
- 订单创建（Outbox 处理器）→ 累加销量后 `indexBook`（**销量实时进 ES**）。

## 4. 查询能力
- **字段维度**：`field=all|title|author`
  - all → `title^3, author^2, description, title.pinyin^2, author.pinyin^2`
  - title → `title, title.pinyin`；author → `author, author.pinyin`
- **分面导航**：筛选走 **`post_filter`**（分类/作者/价格），聚合基于"未筛选候选集"计算 → 选中某分类后其它分类仍显示计数。
- **高亮**：title/author/description（IK 词级，如 `<em>机器</em><em>学习</em>`）。
- **聚合**：分类（`categoryName` keyword，`sterms`）、价格区间（`range` 聚合）。
- **搜索建议**：`GET /api/product/suggest?prefix=` 对 `title.keyword/author.keyword/title.pinyin/author.pinyin` 做 **prefix 查询**，返回去重书名/作者。
- **作者主页**：`GET /api/product/author?name=` → 该作者作品（按销量）+ 分类分布 + 平均评分。

## 5. 降级
- `/search` 与 `/search/rich`：ES 异常 → **回退 MySQL 加权查询**（标题命中优先：`ORDER BY (title LIKE ...) DESC, (author LIKE ...) DESC, rate, sales`），保证可用性。

## 6. 踩坑记录
- `SearchResponse<Book>` 强类型反序列化 `Failed to decode response` → 改用 `SearchResponse<Map>` 手工映射。
- 数值字段 terms 聚合返回 `lterms` 而非 `sterms`；分类分面改用 `categoryName`(keyword)。
- 建索引时若在创建阶段就挂 `isWriteIndex=true` 别名，重建会报"别名多个 write index" → 改为创建时不挂、bulk 后再原子切换。
- `AggregationRange.from/to` 接收 String。
- PowerShell 终端中文/`_analyze` 乱码属终端编码，不影响数据。

## 7. 验证
- `_analyze("机器学习与深度学习")` → IK 词级；`_analyze("周志华")` → `zhouzhihua|zzh`。
- `keyword=zhouzhihua`/`zzh`（作者全拼/首字母）、`jiqixuexi`（书名全拼）均命中。
- `keyword=学习 + categoryName=人工智能`：命中收窄为 3，但分类分面仍显示（3,2）→ 可切换。
- 停 ES 后 `/search` 仍返回（降级 MySQL）。
- mapping 含 `title.pinyin/author.pinyin`、`dynamic=strict`；写未声明字段 → 400。
